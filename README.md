# DEWA — движение в своём ритме

[Открыть сайт](https://savokingi.github.io/dewa-stretching/) · [Исходники](https://github.com/savokingi/dewa-stretching)

Авторский адаптивный сайт на чистых HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются. Главная страница: `dist/index.html`.

## Запуск

Можно открыть `dist/index.html` непосредственно в браузере. Для разработки из этой папки:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Затем открыть http://127.0.0.1:4173/.

## Что реализовано

- Авторская адаптивная композиция, локальные шрифты и фотографии.
- Интерактивный каталог с фильтрами и подробностями шести направлений.
- Переключение дней и выбор конкретного занятия.
- Окно первого знакомства с сохранением выбранного занятия.
- Подготовка сообщения для администратора в Telegram: посетитель отправляет его самостоятельно.
- Профили тренеров, галерея с клавиатурной навигацией, FAQ и маршрут.
- Мобильное меню, управление фокусом, ограничение движения при системной настройке reduced motion.
- Переходы в действующее расписание, личный кабинет, блог и социальные сети студии.

## Данные и запись

Это презентационный сайт без собственного сервера записи и платёжной системы. Он не принимает оплату, не хранит введённое имя и не показывает ложное подтверждение бронирования. Запись подтверждает студия через действующие каналы.

Расписание 2–4 ноября 2026 года и цены — статический снимок информации из официального сайта на 1 ноября 2026 года. Они редактируются в `dist/app.js` и `dist/index.html`. Перед публичным коммерческим использованием нужно сверить их с клубом или подключить действующий API/CRM. Число свободных мест намеренно не моделируется.

## Материалы

Фотографии, сведения о направлениях и тренерах взяты с https://dewastretching.ru/ и его публичных разделов. Исходные адреса фотографий сохранены в `asset-sources.json`. Материалы принадлежат соответствующим правообладателям; сайт создан как концепция DEWA.

Шрифты Cormorant Garamond и Manrope загружаются локально. Лицензии находятся в папке `licenses`.

## Устройство

- `dist/index.html` — содержимое и семантическая структура.
- `dist/styles.css` — базовая система дизайна, адаптивность и анимации.
- `dist/editorial.css` — индивидуальная редакционная композиция, афиша занятий и прайс-лист.
- `dist/app.js` — каталог, расписание, окна и навигация.
- `dist/assets/` — локальные изображения, шрифты и значок.

Сайт не вносит изменений в официальный сайт клуба и его аккаунты. Новая публикация размещается отдельно.

## Публикация на GitHub Pages

Основная ветка содержит исходники. Ветка `gh-pages` содержит только содержимое `dist/`. Сайт полностью статический, без установки зависимостей и серверной сборки. `.nojekyll` отключает лишнюю обработку.

Оригинальный логотип взят из публичного Telegram-канала DEWA.
